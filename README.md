Project Name: Artwork Maestro

Description: Developed a showcase website for a hornware product, fostering trust and brand recognition for potential buyers. This non-e-commerce platform utilizes Next.js and React for a dynamic and engaging user experience. Implemented a user-friendly UI with Tailwind CSS, incorporating basic animations for a visually appealing presentation. Leveraged GitHub for version control and Vercel for seamless deployment.
